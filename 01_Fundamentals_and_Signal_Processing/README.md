# Fundamentals and Signal Processing

MATLAB exercises covering basic signal generation and visualization, linear input-output system analysis, least-squares line fitting, pulse-based time-delay estimation, and audio playback and resampling.

## Requirements
- MATLAB
- Signal Processing Toolbox for the `resample`-based audio example

## Run
Open this folder in MATLAB and run the required script. The scripts in Part 2 use `data/p2.mat`; the audio exercise uses `data/voice.wav`. For those scripts, set the current folder to this directory or update the data path to `data/...`.
