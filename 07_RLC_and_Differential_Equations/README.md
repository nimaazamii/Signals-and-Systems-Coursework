# RLC Systems and Differential Equations

MATLAB and Simulink exercises for modeling an RLC system and solving a second-order ordinary differential equation with specified initial conditions.

## Requirements
- MATLAB
- Simulink for the `.slx` models
- Symbolic Math Toolbox for `q3.m`

## Run
Open the `.slx` files in Simulink. Run `q3.m` from MATLAB for the symbolic differential-equation solution.
