# License Plate Recognition

MATLAB exercises on image preprocessing and character recognition for English and Persian license plates. The implementations include grayscale conversion, thresholding, connected-component processing, character segmentation, and template matching against training samples.

## Requirements
- MATLAB
- Image Processing Toolbox

## Data
Training templates are stored alongside the scripts. Example images are stored in `data/sample_images/`.

## Run
Open this folder in MATLAB and run `p1.m`, `p2.m`, or `p3.m`. The scripts prompt for an input image. The required training MAT-files are included in this folder.
