# Fourier Analysis and Frequency-Based Encoding

MATLAB exercises on discrete-time Fourier analysis using the FFT, centered frequency spectra, magnitude and phase visualization, and a frequency-based text communication scheme with noise sensitivity analysis.

## Requirements
- MATLAB

## Run
Run `q0.m`, `q1.m`, or `q1_2.m` for Fourier examples. Run `q2_1.m` for the text encoding and decoding experiment.
