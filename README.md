# Signals and Systems Coursework

A curated collection of MATLAB and Simulink coursework projects covering signal analysis, image processing, digital communication, audio processing, radar signal estimation, and dynamic-system modeling.

## Projects
- `01_Fundamentals_and_Signal_Processing`: signal generation, system analysis, curve fitting, pulse timing, and audio processing.
- `02_License_Plate_Recognition`: image preprocessing, segmentation, and template-based character recognition.
- `03_Image_Audio_and_Signal_Applications`: image steganography, DTMF decoding, template matching, and audio-based number generation.
- `04_Amplitude_Modulation_Communication`: amplitude-based digital text transmission and noise analysis.
- `05_Fourier_and_Frequency_Encoding`: FFT analysis and frequency-based text encoding.
- `06_Radar_and_Audio_Processing`: radar target estimation and audio tone analysis.
- `07_RLC_and_Differential_Equations`: Simulink models and symbolic ODE solution.

Each project folder contains its own README with requirements and execution notes. These are coursework implementations; they have not all been independently revalidated in a current MATLAB/Simulink environment.
