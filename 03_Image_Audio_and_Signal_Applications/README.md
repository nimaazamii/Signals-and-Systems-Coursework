# Image, Audio, and Signal Applications

A collection of MATLAB exercises applying signal-processing concepts to image steganography, DTMF tone generation and decoding, image-template matching for component localization, and spoken-number audio assembly.

## Requirements
- MATLAB
- Image Processing Toolbox for image input and display functions

## Data
Required images, audio samples, and the `Map Set` audio directory are included in this folder.

## Run
Run the relevant `question*.m` script from this folder. Run the script with this folder as the MATLAB current folder so it can find its input files and the `Map Set` directory.
